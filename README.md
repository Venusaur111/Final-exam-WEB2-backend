# Exam Manager Backend

## Overview
Backend API for the Exam Manager application, built with Node.js, Express, TypeScript, and PostgreSQL. It implements a layered architecture separating routing, business logic, and data access.

## Prerequisites
* Node.js (v18 or higher)
* pnpm package manager
* PostgreSQL (running locally or accessible via connection string)
